# AR Jewel - Edge Computing Edition

Application d'essayage de bijoux en Réalité Augmentée utilisant l'Edge Computing pour un tracking fluide et performant.

## Technologies
- **Frontend**: Next.js, React, Three.js
- **AR Tracking**: MediaPipe Tasks Vision (Edge Computing)
- **State Management**: Zustand

## Structure du projet
- `apps/web`: Application principale Next.js

## Installation
```bash
cd apps/web
npm install
npm run dev
```
